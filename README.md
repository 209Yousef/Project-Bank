# Bank Management System – C#

A console-based Bank Management System developed in C# as part of my programming and problem-solving learning journey.

The project includes two stages: **Bank1** and **Bank Extension**, demonstrating the development and expansion of a banking management application.

## Project Overview

The purpose of this project is to practice C# programming fundamentals by building a practical banking application.

The project focuses on organizing program logic, working with client information, and implementing banking-related functionality.

## Project Structure

### 1. Bank1

The initial version of the Bank Management System, focusing on the core application structure and fundamental banking management functionality.

### 2. Bank Extension

An extended version of the original Bank1 project, developed to expand the application's functionality and provide additional programming practice.
